## SR Verge چیست؟

SR Verge یک برنامه‌ی دسکتاپ برای اتصال به اینترنت از طریق سرورهای پروکسی
(کانفیگ‌های V2Ray / Xray / Clash) است. کافی است لینک اشتراک (Subscription)
را اضافه کنید یا لینک کانفیگ را وارد کنید، یک سرور انتخاب کنید و اتصال را
روشن کنید. می‌توانید کل ترافیک سیستم را از پروکسی عبور دهید، یا فقط
برنامه‌ها و سایت‌هایی که خودتان انتخاب می‌کنید.

SR Verge نسخه‌ی توسعه‌یافته‌ی (Fork) برنامه‌ی
[Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev)
است. همه‌ی امکانات Clash Verge را دارد و قابلیت‌هایی برای شبکه‌های
فیلترشده، به‌خصوص در ایران، به آن اضافه شده است.

## دانلود و نصب

آخرین نسخه را از
[صفحه‌ی Releases](https://github.com/sinarajabpour/SR-VERGE/releases/latest)
دانلود کنید.

| سیستم‌عامل                 | فایل مورد نیاز                     |
| :------------------------- | :--------------------------------- |
| ویندوز ۱۰ و ۱۱ (۶۴ بیتی)   | `SR.Verge_x.y.z_x64-setup.exe`     |
| مک (Apple Silicon)         | `SR.Verge_x.y.z_aarch64.dmg`       |
| لینوکس (۶۴ بیتی)           | فایل `.deb` یا `.rpm` |

فایل‌های نصبی امضای دیجیتال ندارند، به همین دلیل ممکن است بار اول هشدار ببینید:

- **ویندوز:** اگر پیام SmartScreen نمایش داده شد، روی
  **More info** و بعد **Run anyway** کلیک کنید.
- **مک:** برنامه را داخل پوشه‌ی *Applications* بکشید. اگر پیام «برنامه
  آسیب دیده است» یا «باز نمی‌شود» دیدید، یک بار این دستور را در Terminal
  اجرا کنید:

</div>

```shell
sudo xattr -r -d com.apple.quarantine "/Applications/SR Verge.app"
```

### روشن کردن حالت TUN

حالت TUN **همه‌ی** ترافیک سیستم را (حتی برنامه‌هایی که به پروکسی سیستم
توجه نمی‌کنند) از SR Verge عبور می‌دهد. برای این کار یک سرویس کمکی لازم است:

1. به **تنظیمات ← تنظیمات سیستم** بروید.
2. روی آیکون 🔧 (آچار) کنار **حالت Tun** کلیک کنید و رمز مدیر سیستم
   (Administrator) را وارد کنید تا سرویس نصب شود.
3. کلید **حالت Tun** را روشن کنید.

در **ویندوز** می‌توانید بدون سرویس هم از حالت TUN استفاده کنید: روی SR Verge
راست‌کلیک کنید، **Run as administrator** را بزنید و سپس **حالت Tun** را روشن کنید.

## امکانات

### همه‌ی امکانات Clash Verge

- ساخته‌شده با Rust و Tauri 2؛ سریع و سبک.
- هسته‌ی داخلی [mihomo (Clash Meta)](https://github.com/MetaCubeX/mihomo)
  با امکان استفاده از نسخه‌ی Alpha.
- حالت **پروکسی سیستم** و حالت **TUN (کارت شبکه‌ی مجازی)**.
- حالت‌های Rule، Global و Direct، به همراه ویرایش گرافیکی سرورها و قوانین.
- مدیریت پروفایل‌ها، Merge و Script، و راهنمای نوشتار کانفیگ.
- نمایش زنده‌ی اتصال‌ها، ترافیک، لاگ‌ها و تست پینگ.
- تم، آیکون سینی سیستم و CSS دلخواه.
- پشتیبان‌گیری و همگام‌سازی با WebDAV.

### قابلیت‌های جدید SR Verge (که Clash Verge ندارد)

| قابلیت | توضیح |
| :--- | :--- |
| **اشتراک‌های V2Ray و Base64** | اشتراک‌های نوع V2Ray (فهرست Base64 یا متنی از لینک‌ها، مثل خروجی پنل‌های Marzban، 3x-ui، Hiddify و بیشتر سرویس‌دهنده‌های ایرانی) را مستقیماً وارد می‌کند و خودکار به پروفایل Clash Meta تبدیل می‌کند. Clash Verge فقط فایل YAML مخصوص Clash را می‌پذیرد. |
| **پشتیبانی از همه‌ی فرمت‌های رایج لینک** | `vless://` (REALITY و Vision)، `vmess://` (فرمت‌های v2rayN، Shadowrocket و Xray)، `trojan://`، `ss://` (همراه با Shadowsocks 2022 و پلاگین‌های obfs و v2ray-plugin)، `ssr://`، `hysteria://`، `hysteria2://` و `hy2://` (همراه با port hopping)، `tuic://`، `anytls://`، `socks://` و `wireguard://`. ترنسپورت‌ها: TCP، هدر HTTP، WebSocket (همراه با early data)، HTTPUpgrade، HTTP/2، gRPC و XHTTP. |
| **وارد کردن مستقیم لینک کانفیگ** | یک یا چند لینک (`vless://…`، `vmess://…` و…)، حتی چند لینک در یک خط، یا متن Base64 خام را در کادر وارد کردن پیست کنید. به لینک اشتراک نیازی نیست. لینک‌های `clash://install-config`، `sub://` و `hiddify://import` هم پشتیبانی می‌شوند. |
| **یک سرور خراب کل پروفایل را از کار نمی‌اندازد** | هسته‌ی mihomo اگر حتی یک سرور نامعتبر باشد کل کانفیگ را رد می‌کند. SR Verge هنگام وارد کردن و به‌روزرسانی، پروفایل را با خود هسته بررسی می‌کند، سرورهای غیرقابل‌استفاده را کنار می‌گذارد و نام آن‌ها را به شما اعلام می‌کند. |
| **کانفیگ‌های Clash ناقص هم درست کار می‌کنند** | اشتراک Clash که فقط فهرست `proxies` دارد (بدون گروه و قانون)، یک انتخاب‌گر سرور و قوانین مسیریابی دریافت می‌کند، به جای اینکه بی‌صدا همه‌ی ترافیک را مستقیم بفرستد. |
| **پیام خطای واضح هنگام وارد کردن** | اگر لینک مسدود یا منقضی شده باشد (و یک صفحه‌ی وب برگرداند) یا کانفیگ از نوع JSON مخصوص sing-box/Xray باشد، پیامی قابل‌فهم نمایش داده می‌شود، نه «invalid yaml». |
| **رفع مشکل نام‌های تکراری** | بعضی سرویس‌دهنده‌ها چند سرور با نام یکسان می‌فرستند و هسته‌ی mihomo آن را رد می‌کند. SR Verge هنگام وارد کردن، نام‌های تکراری را تغییر می‌دهد تا پروفایل بدون خطا بارگذاری شود. |
| **DNS سازگار با فیلترینگ در حالت TUN** | در حالت TUN، آدرس سرورها اول با DNS سیستم پیدا می‌شود، نه با سرورهای DoH مسدودشده (Cloudflare/Google). در ایران سرورها در حالت TUN دیگر تایم‌اوت نمی‌شوند و وصل می‌شوند. |
| **مسیریابی ایران با یک کلیک** | دو دکمه در صفحه‌ی **قوانین** که سایت‌ها و IPهای ایرانی را **مستقیم** و بقیه را از پروکسی عبور می‌دهند: <br>• **اتصال مستقیم ایران**: از داده‌های جغرافیایی داخل برنامه استفاده می‌کند و بدون اینترنت هم کار می‌کند. <br>• **اتصال مستقیم ایران (لیست آنلاین)**: یک فهرست بسیار بزرگ‌تر از دامنه‌های ایرانی اضافه می‌کند که در پس‌زمینه به‌روز می‌شود. |
| **مسیریابی بر اساس سایت و برنامه** | مشخص کنید کدام سایت‌ها یا برنامه‌ها (مثلاً `Telegram.exe`) بدون پروکسی وصل شوند یا همیشه از پروکسی استفاده کنند. ترافیک شبکه‌ی محلی (مودم، NAS، localhost) مستقیم می‌ماند و گزینه‌ی **DIRECT** هم به فهرست سرورها اضافه شده است. |
| **ویرایشگر قوانین و قوانین سراسری** | ویرایش قوانین مسیریابی از صفحه‌ی قوانین، با قالب آماده و مثال. قوانین سراسری روی همه‌ی پروفایل‌ها اعمال می‌شوند و با به‌روزرسانی اشتراک پاک نمی‌شوند. قانونی که به گروهی اشاره کند که در پروفایل فعلی وجود ندارد، نادیده گرفته می‌شود (و در لاگ ثبت می‌شود) و کل پروفایل را از کار نمی‌اندازد. |
| **کارکرد درست `prepend-rules` و `append-rules`** | این کلیدها در Global Extend Config حالا درست اعمال می‌شوند. قبل از این اصلاح، بدون هیچ پیامی نادیده گرفته می‌شدند. |
| **سرویس TUN پایدار در مک و ویندوز** | سرویس کمکی TUN دقیقاً با همان نسخه‌ای که برنامه با آن کار می‌کند همراه برنامه ارائه می‌شود (ناهماهنگی نسخه باعث خطای «Install Service failed: IPC path not ready» می‌شد) و نصب مجدد سرویس در ویندوز منتظر حذف کامل سرویس قبلی می‌ماند. |
| **قفل نشدن برنامه هنگام قطع اینترنت** | بررسی کانفیگ حالا حداکثر ۲۰ ثانیه طول می‌کشد. با قطع شدن اینترنت، برنامه دیگر تا راه‌اندازی مجدد سیستم قفل نمی‌ماند. |
| **رابط کاربری فارسی** | ترجمه‌ی فارسی بهبودیافته با فونت وزیرمتن. |
| **بدون به‌روزرسانی خودکار ناخواسته** | بررسی خودکار به‌روزرسانی نسخه‌ی اصلی غیرفعال است، پس برنامه هیچ‌وقت خودش را با Clash Verge جایگزین نمی‌کند. |

## ساخت از سورس

[پیش‌نیازهای Tauri](https://tauri.app/start/prerequisites/)، Node.js و pnpm
را نصب کنید و سپس اجرا کنید:

</div>

```shell
pnpm i
pnpm run prebuild
pnpm dev
```

<div dir="rtl">

برای اجرای تست‌های بخش اصلی برنامه (خواندن لینک‌ها، وارد کردن و به‌روزرسانی
پروفایل و قوانین) از دستورهای زیر استفاده کنید. برای اینکه کانفیگ‌های ساخته‌شده
با خود هسته هم بررسی شوند، مسیر فایل اجرایی mihomo و پوشه‌ای که فایل‌های
`geosite.dat` و `Country.mmdb` در آن است را بدهید:

</div>

```shell
cargo test -p clash-verge
SR_VERGE_MIHOMO=/path/to/mihomo SR_VERGE_GEODATA=/path/to/geodata cargo test -p clash-verge
```

<div dir="rtl">

برای انتشار نسخه‌ی جدید، یک تگ نسخه (مثلاً `v2.6.0`) push کنید یا workflow
با نام **Release** را از تب Actions اجرا کنید. GitHub Actions فایل‌های نصبی
ویندوز، مک و لینوکس را می‌سازد و به‌صورت یک Release منتشر می‌کند.
